# odintictactoe
The Odin Project - Tic Tac Toe

A tic-tac-toe game first coded in a console version to make sure game logic works.
Then it was ported to a HTML version with interactive DOM elements. The code has a lot of different transitions and style changes to elements to have smooth transitions to different stages. The code can therefore look a bit cluttered but most of it is just for visual purposes.
